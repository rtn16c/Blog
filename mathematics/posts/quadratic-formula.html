Quadratics 2: Solving with the Quadratic Formula

21 October 2026
algebra quadratics quadratic-formula discriminant

The quadratic formula can be used when our standard form quadratic equations don't factor out neatly.

It can also be used for quadratic equations that do factor, but often it is just quicker to factor them and work it out than go through all the steps for the quadratic formula.

The Quadratic Formula

This is what the quadratic formula looks like:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Notice how the letters \(a\), \(b\), and \(c\) also appear here, just like they do in the standard form \(ax^2 + bx + c = 0\)?

That means if we have a standard form quadratic that we can't solve by factorising, we can just take the \(a\), \(b\), and \(c\) values and plug them straight into this formula.

Pre-requisite: Your equation must be in standard form (\(ax^2 + bx + c = 0\)) before you can use the quadratic formula. If it isn't, rearrange it first. See Quadratics 1 for a refresher on standard form and rearranging.

General Steps

  1. Identify your \(a\), \(b\), and \(c\) values
  2. Substitute them into the quadratic formula
  3. Simplify
  4. Solve for \(+\) and \(-\)

Example 1 — a result with a neat square root

$$x^2 + 2x - 3 = 0$$

Here \(a = 1\), \(b = 2\), \(c = -3\). Substituting in:

$$x = \frac{-2 \pm \sqrt{2^2 - 4(1)(-3)}}{2(1)}$$ $$x = \frac{-2 \pm \sqrt{4 + 12}}{2} = \frac{-2 \pm \sqrt{16}}{2}$$

Since \(\sqrt{16} = 4\):

$$x = \frac{-2 + 4}{2} = 1 \qquad \text{or} \qquad x = \frac{-2 - 4}{2} = -3$$

Example 2 — a result without a neat square root

$$x^2 - 5x + 3 = 0$$

Here \(a = 1\), \(b = -5\), \(c = 3\). Substituting in:

$$x = \frac{-(-5) \pm \sqrt{(-5)^2 - 4(1)(3)}}{2(1)}$$ $$x = \frac{5 \pm \sqrt{25 - 12}}{2} = \frac{5 \pm \sqrt{13}}{2}$$

\(13\) doesn't have a neat square root, so the answer is left in surd form:

$$x = \frac{5 + \sqrt{13}}{2} \qquad \text{or} \qquad x = \frac{5 - \sqrt{13}}{2}$$

The Discriminant

The discriminant is the expression under the square root: \(b^2 - 4ac\). Evaluating it before you start the full formula can tell you straight away what kind of answer to expect.

  • Positive discriminant — two different real solutions
  • Zero discriminant — one repeated real solution
  • Negative discriminant — no real solutions. You can't take the square root of a negative number (within real numbers). This crosses over into more advanced mathematics involving imaginary and complex numbers, which won't be covered here.

Practice Questions

Question 1

$$x^2 - 6x + 2 = 0$$
Show solution

\(a = 1,\ b = -6,\ c = 2\)

Check the discriminant first:

$$b^2 - 4ac = (-6)^2 - 4(1)(2) = 36 - 8 = 28$$

Positive, so there are two real solutions. We proceed:

$$x = \frac{-(-6) \pm \sqrt{28}}{2(1)} = \frac{6 \pm \sqrt{28}}{2}$$

We can simplify \(\sqrt{28}\) — note that \(28 = 4 \times 7\), and \(\sqrt{4} = 2\), so \(\sqrt{28} = 2\sqrt{7}\):

$$x = \frac{6 \pm 2\sqrt{7}}{2}$$

The factor of \(2\) in the numerator cancels with the \(2\) in the denominator:

$$x = 3 \pm \sqrt{7}$$

Question 2

$$2x^2 + x - 4 = 0$$
Show solution

\(a = 2,\ b = 1,\ c = -4\)

Check the discriminant first:

$$b^2 - 4ac = (1)^2 - 4(2)(-4) = 1 + 32 = 33$$

Positive, so there are two real solutions. We proceed:

$$x = \frac{-(1) \pm \sqrt{33}}{2(2)} = \frac{-1 \pm \sqrt{33}}{4}$$

Note that \(\sqrt{33}\) cannot be simplified — the factors of \(33\) are \(11 \times 3\), and neither \(11\) nor \(3\) is a perfect square.

Question 3

$$x^2 + 2x + 5 = 0$$
Show solution

\(a = 1,\ b = 2,\ c = 5\)

Check the discriminant first:

$$b^2 - 4ac = (2)^2 - 4(1)(5) = 4 - 20 = -16$$

The discriminant is negative. The square root of \(-16\) is not a real number, so this equation has no real solutions.
